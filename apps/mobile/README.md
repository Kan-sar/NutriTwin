# NutriTwin Flutter client

Meal edits and deletions send the loaded revision. If another tab changes the meal, the client keeps the draft and shows a conflict. Use Refresh journal to compare saved state; select Edit on the refreshed meal before reapplying changes.

Flutter stable 3.47.2 / Dart 3.13.2. The shared client currently targets Web. Android/iOS toolchains and packaging are not installed or verified.

Start the backend with `docker compose -f infra/docker/compose.yaml up --build -d` from the repository root. From this directory run `flutter --no-version-check pub get`, `flutter --no-version-check test`, and `flutter --no-version-check run -d chrome --web-hostname 127.0.0.1 --web-port 8080`.

If the Windows Flutter launcher stalls on version checking, the already-built tool can be invoked directly:

```powershell
& C:\apps\flutter\bin\cache\dart-sdk\bin\dart.exe C:\apps\flutter\bin\cache\flutter_tools.snapshot --no-version-check --suppress-analytics build web --release --no-web-resources-cdn
```

Serve `build/web` on loopback port 8080. The default API is `http://127.0.0.1:8000`; override at build time with `--dart-define=API_BASE_URL=https://your-api-origin`. Configure exact CORS origins on the API. Do not expose local demonstration accounts publicly.

The manual workflow covers registration, consent/profile, source-bearing food search, meals with dates/times and gram amounts, daily/rolling totals, history/explanations, demo ranking and constrained construction, preferences, manual INR prices, and Admin scientific review. Constructed meals become editable drafts and are not saved automatically.

Tokens live only in memory; refresh uses one shared rotation for concurrent expired requests. Logout clears local credentials even on a failed network call. Reloading the page requires sign-in. Missing composition remains unavailable, and all demo targets/prices are labeled. Quantitative evidence is never generated by the client. See `docs/SCIENTIFIC_IMPORT.md` for the Admin proposal contract.

Run `dart format --output=none --set-exit-if-changed lib test`, `flutter --no-version-check analyze`, and `flutter --no-version-check test`. The generated Web release was exercised with installed Chrome through Playwright. Offline synchronization, native secure token storage, additional locales, and comprehensive assistive-technology certification remain outstanding.
