# Flutter client status

Status: **deferred**.

Flutter remains the primary client required by the final specification, but the Flutter SDK is unavailable on the current development host. No mock UI is included because it would conceal the missing client implementation.

The first mobile milestone must implement authentication, consent, Student/Adult profile, food search, ingredient-level meal logging, distinct consumed/effective/target views, daily/7-day/30-day trends, risk trace, recommendation trace, loading/empty/error/offline states, medical disclaimer, and accessibility tests against the stable `/api/v1` contract.
